# Redes

Proyectos de práctica en redes y ciberseguridad, desarrollados en Python, HTML y CSS.

## Proyectos incluidos

### 📡 network-monitor
Herramienta en Python que hace ping periódico a una lista de hosts/IPs (routers, servidores, gateways) y registra su disponibilidad en un log con marca de tiempo.

**Uso:**
```bash
cd network-monitor
python monitor.py
```
Configura los hosts a monitorear en `config.py`.

### 🔍 port-scanner
Escáner de puertos TCP básico, hecho como ejercicio de aprendizaje sobre sockets y fundamentos de ciberseguridad. Uso solo en equipos propios o con autorización explícita.

**Uso:**
```bash
cd port-scanner
python scanner.py 127.0.0.1 1 1024
```

### 🌐 portfolio-site
Página web simple (HTML + CSS) para presentar experiencia profesional y proyectos. Se puede publicar gratis con GitHub Pages.

**Uso:** abre `portfolio-site/index.html` en el navegador.
